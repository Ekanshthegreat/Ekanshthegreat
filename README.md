## 👋 About Me

I'm Ekansh, a Computer Science student at Simon Fraser University interested in distributed systems, cloud infrastructure, AI, and robotics.

I've previously worked on:
- ☁️ AWS CloudFormation — infrastructure tooling for safely refactoring resources across stacks
- 💳 Amazon — distributed systems for recurring payments at scale
- 🤖 Visier — LLM-powered analytics and ML infrastructure

Outside of work, I like building things that force me to learn something new — from robot fleet orchestration and AI developer tools to drones and trading systems.

## 🔨 What I'm Building

### 🤖 NodeAI
A real-time robot fleet orchestration platform for coordinating 100+ simulated robots.

`Python` `FastAPI` `React` `TypeScript` `WebSockets`

- Mission scheduling and dynamic task allocation
- Real-time telemetry processing
- A* pathfinding and failure recovery
- 3D fleet visualization

### 🧠 Mentral.AI
An AI coding mentor that learns how a repository is written from its code and Git history.

`TypeScript` `Node.js` `Gemini` `RAG` `WebSockets`

- AST-based code analysis
- Semantic retrieval over repository context
- Git-history-aware code reviews
- Built at Hack the North
